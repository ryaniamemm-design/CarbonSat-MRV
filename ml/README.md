# FVC and NPP anomaly prescreening

Two Isolation Forest model families support advisory review prioritization. The browser workbench does not run these models, and its 172 exported review tasks come from ledger rules.

| Family | Inputs | Features | Roles |
|---|---|---|---|
| FVC v1.1 | 3,420 rows, 90 cells, 1987–2024 | 7 | Formal scoring; 72/18-cell training/holdout split |
| NPP v1.0 | 816 rows, 34 cells, 2001–2024 | 8 | Formal scoring; time holdout; cell holdout |

Five saved artifacts are supplied: one formal FVC model, three NPP artifacts and one isolated synthetic FVC smoke model. They represent two formal model families. The synthetic artifact is never a formal scientific result.

## Environment

The packaged models were checked with Python 3.12 and the versions in `requirements.txt`:

```bash
python -m venv .venv
# Activate the environment using the command appropriate for your operating system.
python -m pip install -r ml/requirements.txt
python ml/tools/verify_models_readonly.py
python ml/project/pipeline/tests/test_fvc_preprocessing.py
```

Run commands from the repository root. The verifier checks the packaged artifact/input hashes before loading trusted joblib files, forbids fitting, compares 3,420 FVC and 816 NPP scores, and checks that model bytes remain unchanged. Load model files only from a source you trust; the manifest is an integrity record, not an authentication mechanism.

## Layout

- `project/pipeline/anomaly_model.py`: FVC feature preparation, training and inference implementation.
- `project/pipeline/npp_anomaly_model.py`: NPP implementation and distinct scoring/evaluation roles.
- `project/data/`: frozen training and scoring inputs.
- `project/evidence/`: saved models, score tables and role/status metadata.
- `project/gee/`: historical Earth Engine export implementations. The NPP smoke exporter is a historical smoke workflow, not a claim that all displayed production values are regenerated by it.
- `tools/verify_models_readonly.py`: read-only reproduction.
- `MODEL_ARTIFACT_MANIFEST.json`: expected hashes and file sizes of packaged artifacts and inputs.

## FVC v1.1 repair

The repair consistently applies the saved training imputer in the producer and inference paths. The formal forest was not retrained. Compared with the original snapshot, 111 rounded grid scores changed by at most 0.0005, while grid flags and existing claim scores/flags did not change. The development repair is included here as a separate offline module; it does not change the workbench's scientific bundles or claim gates.

Real anomaly-detection performance remains unverified because independently labelled anomalies are unavailable. Synthetic injection metrics are process checks. Neither model predicts carbon credits or establishes restoration causality.

## Training implementation

The source includes training functions for inspection. To experiment with fitting, use a disposable copy: the FVC module's direct entry writes training artifacts, and the NPP `--train` command writes its models and score tables. The submission preparation runs only read-only reproduction and regression checks.
