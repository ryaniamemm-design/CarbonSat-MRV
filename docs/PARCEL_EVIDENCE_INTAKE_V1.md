## 用途

打开 `web/parcel_review.html`，登记候选地块的资料与出处，获得缺项清单，并把登记记录交给专业人员审阅。本模块将 R35.2 的五类资料收集设计转成可操作的页面，不自动选择方法学、不计算碳量、不判定地块合格。

项目入口 `web/entry.html` 已增加链接。页面没有 CDN、钱包或 RPC 依赖；文件读取、摘要重算、下载、导入与本机草稿均在浏览器执行，不上传资料。

## 三步使用

1. 新建真实登记。填写地块编号、主体、措施、时间和权属；导入面状 GeoJSON 并明确 WGS84 经度在前的 EPSG:4326。其他坐标系先在 GIS 中转换。
2. 展开五类资料来源，填写状态、文件名称、出具单位、日期及编号/页码定位。原件可以留在外部档案中；记录出处不代表系统已经读取或鉴定原件。
3. 根据缺项清单补资料，下载 JSON 给审阅者。审阅者导入后可重算内部摘要；若有通过独立可信渠道取得的记录摘要，再做外部比对。附件原件需要另行提供、重新选择并核对字节。

默认真实登记为空白。演示按钮只加载明确标注 SYNTHETIC 的虚构资料和几何，不对应库布其或任何真实项目。不得把演示记录、虚构来源或坐标作项目事实。内置演示编号不允许只切换模式就升级为真实记录。

## 状态与判据

| 状态 | 含义 | 不代表什么 |
|---|---|---|
| 输入有误 | 协议、类型、几何基本结构或日期非法，不能生成核验包 | 不使用旧通过态替代失败输入 |
| 资料不足 | 必要事实或来源尚缺，或关键项标“不适用”需审阅 | 不作肯定资格判断 |
| 资料登记齐备 | 五类来源和必要登记字段齐备，可开始文件内容审阅 | 不等于原件已取得、出处真实、权属有效、资格通过或可登记信用 |
| 包内部核验通过 | 严格结构、规则结果、记录摘要及包摘要可重算 | 不证明资料包未被整体重建替换 |
| 与外部期望摘要一致 | 与另行提供的固定记录摘要一致 | 摘要来源是否可信仍由接收方判断 |
| 附件字节一致 | 当前原件字节和长度与包内登记的值一致 | 不鉴定文书真假、效力或内容正确性 |

五类关键项分别为边界、开工日、措施与物种、权属、治理前土地证据。“部分提供”“未提供”“不适用”均不自动放行。来源不完整、未知 CRS、未来开工/文书、日期窗倒置、权属有效期过期、不同主体缺授权/转让、分批日期/来源不一致和复合活动未拆分会产生具体任务。

分批项目至少登记两个批次，每批绑定开工资料中的来源编号，总开工日应与最早批次一致。造林密度、土地历史真实性、权属对寿命期的覆盖及方法学条件始终保留专业核查。

## 数据与核验契约

- 登记记录：`CarbonSat-ParcelEvidence-v1.0`。
- 完整性规则：`CarbonSat-ParcelCompleteness-v1.1`。
- 下载包：`CarbonSat-ParcelReviewPackage-v1.0`。
- JavaScript 规范串：对象键按字典序排序，使用 ECMAScript JSON 数值表示；拒绝 undefined 和非有限值。不声称与 A2/Python 序列化协议通用。
- 记录摘要：`SHA256(UTF8("CarbonSat-MRV|parcel-record|v1\n" + canonical(record)))`，前缀 `local-sha256:`。
- 包摘要：同样在独立 `parcel-package|v1` 域下计算，覆盖除 `packageSha256` 自身外的全部顶层字段。记录、规则结果、范围声明和时间戳均被覆盖。
- Node 使用原生 crypto，浏览器使用本地 ethers 对同一原始字节计算 SHA256。附件按原始文件字节哈希，绝不先当文本转码。
- 核验器重算完整性规则，不信包内的“齐备”或“资格”声明；即使攻击者同步重算自摘要，错误规则结果或越界边界仍被拒。
- 攻击者若合法地重建了不同内容及全部自摘要，只能得到内部一致；须用外部固定摘要才能检出这种替换。内部校验不是签名或真实性证明。

`eligibilityStatus=NOT_ASSESSED`、`carbonQuantificationStatus=NOT_PERFORMED`、`registrationReady=false`、`sourceAuthenticityVerified=false`、`linksEstablished=0`、`publiclyAnchored=false` 为强制边界，不可由导入包改为肯定状态。

## GeoJSON 与附件范围

接受 Polygon/MultiPolygon，以及包含这些面的 Feature/FeatureCollection，合并保留其坐标。只接受二维经纬度，每环须闭合、非退化、无明显自交，坐标值须有限且在合法范围；限制数量以避免超大输入拖垮页面。

这不是完整 GIS 拓扑或面积验收。孔洞包含关系、多地块重叠、实际连续面积、测地面积、坐标配准与边界真实性需要 GIS/现场核查。不计算 400 m² 方法学门槛，不把 8 米资格折算当面积积分规则，也不把已有 34 格当项目边界。

单个附件最大 25 MiB，最多 50 个；GeoJSON 输入最大约 1.5 MB，下载包导入最大 2.5 MB。下载包仅含原始字节 SHA256、字节数、文件名和来源引用，不包含原件。包核验不会把“有附件摘要”说成“已核附件”。导入后本次字节匹配状态清空，须重新选择原件。

未主动保存时不使用 localStorage。点击“保存本机草稿”后，资料包保存在当前浏览器同源本地存储；“删除本机草稿”只移除此模块的键，不删除磁盘文件。资料中可能包含坐标和权属主体，分享前由用户检查。

## 本地命令

在 `72h-spike/` 下：

```powershell
node scripts/verify_parcel_package.js --selftest
npx hardhat test test/parcel_intake.test.js
node scripts/verify_parcel_package.js --package path/to/parcel-review.json
node scripts/verify_parcel_package.js --package path/to/parcel-review.json --expected-record-sha256 local-sha256:<可信记录摘要>
.venv-ee/Scripts/python.exe scripts/verify_parcel_module.py --verify
.venv-ee/Scripts/python.exe scripts/verify_parcel_upgrade_snapshot.py
node scripts/browser_parcel_intake_drive.js
```

CLI 任一非法结构、语义、摘要或外部比对失败即 exit 1。浏览器驱动自建临时 loopback 服务与独立 Edge 无头进程，执行真实文件选择和磁盘下载，结束后关闭本次进程和服务；不接触用户已有浏览器或公共网络。

运行本地默认门禁不使用 `-WithChain`；该可选参数会刷新历史链上报告。本模块不依赖链上读回。
