CarbonSat-MRV

An auditable satellite evidence pipeline for vegetation productivity — with a read-only review workbench.

Review workbench → 34 footprint cells × 24 years. Inspect one number, switch years and metrics, read the five-part provenance panel, and hand off to the change ledger. Change ledger → Locate a cell, compare the same cell across adjacent years inside one era, read the per-entry limits, export a review task list.

What this demo does not do

  • It does not produce carbon removals, carbon credits, or any tradable quantity. NPP here is a modelled productivity value.
  • It does not accept a project boundary or geometry input, and it will not promote a record past its evidence gate.
  • It does not report a detection rate or any accuracy figure — there is no labelled reference to measure against.
  • The basemap is off by default; with it off the page makes no external requests.

The pages load their JSON siblings over HTTP. If you opened this file from disk, run a local static server (see the repository README) instead of double-clicking.
